

# 🚀 Bootcamp Ri Happy by Dio - Front End do Zero

Este repositório contém os projetos desenvolvidos durante o **Bootcamp Ri Happy**, oferecido pela **DIO (Digital Innovation One)**, com foco no aprendizado de **Front-End** desde o início.

## 🛠️ Tecnologias Utilizadas:

- **HTML**: Estruturação e organização do conteúdo da página.
- **CSS**: Estilização e design responsivo das interfaces.
- **JavaScript**: Implementação da lógica e interatividade das páginas.

## 📚 Sobre o Bootcamp:

O bootcamp foi desenvolvido para capacitar novos desenvolvedores a se tornarem especialistas em **Front-End** com uma jornada prática, abordando as principais tecnologias e conceitos essenciais para a criação de websites interativos e dinâmicos.
